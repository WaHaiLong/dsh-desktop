使用教程

从安装到连上金蝶,一步步来。

快速开始

  1. 从官网下载或Releases获取对应平台的安装包。
  2. 安装并启动应用。
  3. 打开 设置 → 金蝶 MCP 设置 填入连接参数。
  4. 用自然语言提问,开始操作金蝶 ERP 单据。

应用打包了独立的 Node.js 运行时,不需要在系统里安装 Node.js 或 Python;金蝶 MCP 所需的 Python 与 kingdee-mcp 由内置 uv 在首次运行时自动下载。

金蝶 MCP 配置指南

内置对接 kingdee-mcp——一个金蝶云星空 MCP 服务器,让 AI 用自然语言查询/操作金蝶 ERP 单据(采购/销售/库存/生产/成本/固定资产)。

配置界面

菜单 设置 → 金蝶 MCP 设置,填写 4 个连接参数:

参数说明
KINGDEE_SERVER_URL金蝶云星空 WebAPI 地址,必须包含 /k3cloud/,如 https://your-server/k3cloud/
KINGDEE_ACCT_ID账套 ID
KINGDEE_USERNAME登录用户名
KINGDEE_PASSWORD登录密码

保存后的行为

  1. 应用以 --patch 覆盖层把 mcp-client 配置写入 dsh,并重启服务器。
  2. dsh 通过捆绑的 uv 二进制启动 kingdee-mcp(uv tool run kingdee-mcp)。
  3. 首次运行自动下载 Python + kingdee-mcp 到 uv 缓存。

常见问题

首次连接慢 / Python 下载失败?
uv 捆绑在应用内,但 Python 和 kingdee-mcp 首次运行才下载。网络受限时可更换网络重试,或在有 uv 的机器上先执行 uv tool run kingdee-mcp 预热。

提示服务器地址无效?
确认 KINGDEE_SERVER_URL 以 /k3cloud/ 结尾,且本机可访问该地址。

不想用金蝶 MCP?
不保存配置即可,dsh 本身可独立使用。

构建与发布

本地构建

只需要构建机器上装有 Node.js(任意较新版本)。

npm install                 # 应用 devDeps(electron、electron-builder)
npm run fetch:node          # 为当前平台下载独立 Node → resources/node/
npm run runtime:install     # 安装 @deepseek-ai/dsh → resources/dsh/node_modules/
npm run dist                # 在 dist/ 下生成安装包
# 或一键执行:npm run build

注意:每个平台要在对应平台上构建——捆绑的独立 Node 二进制是分系统的。

CI 自动构建

.github/workflows/release.yml 手动触发,三平台并行(macOS / Ubuntu / Windows),各自构建完直接上传到同一个 GitHub Release。

发布流程

GitHub 仓库 → Actions → release → Run workflow

CI 跑完后自动发布到 GitHub Releases,官网下载按钮直接指向最新版本,无需手动下载上传。
