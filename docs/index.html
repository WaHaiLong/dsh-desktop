📖 遇到系统提示「无法验证开发者 / 已损坏 / 未知发布者」怎么办？

当前为免费版，应用暂未购买代码签名证书，因此 macOS / Windows 首次打开会弹出系统警告。这并非病毒，按下面操作即可正常使用：

🍎 macOS — 提示「已损坏，无法打开」或「无法验证开发者」：

xattr -cr "/Applications/DeepSeek Harness.app"

或：右键 App → 打开 → 仍要打开（先把 App 拖进「应用程序」再操作）。

🪟 Windows — 提示「Windows 已保护你的电脑」：点击 「更多信息」→「仍要运行」。

正式版上线后会完成代码签名，届时不会再出现这些提示。

快速开始

三步,让 AI 开始帮你操作金蝶。

从上面选择你的平台,下载并安装 DeepSeek Harness Desktop。

打开应用,进入 设置 → 金蝶 MCP 设置,填写 4 个连接参数(服务器地址、账套、用户名、密码)。

在对话框中用自然语言提问,例如:帮我查这个月采购订单总额。
